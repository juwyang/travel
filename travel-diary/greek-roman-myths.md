希腊和罗马神名字多有对应：

希腊 宙斯 Zeus 罗马 朱庇特Jupiter 经典故事 变成公牛劫夺腓尼基公主欧罗巴；雷霆

酒神 狄俄倪索斯Dionysus // 巴库斯Bacchus 发明了葡萄酒并和随从周游世界，传播酿酒技术

爱与美神 阿佛洛狄忒 Aphrodite // 维纳斯Venus 金苹果故事，特洛伊战争

太阳神 阿波罗 Apollo 被丘比特射箭，阿波罗和达芙妮 贝尼尼雕塑 博尔盖塞

天后 赫拉 Hera 朱诺 Juno 一生和宙斯的情人们斗智斗勇。宙斯外出，派Echo山林仙女，拖住赫拉，给她讲八卦。赫拉反应过来，施咒Echo只能重复别人。

海洋 波塞冬 Poseidon // Neptune 宙斯、波塞冬、哈迪斯三兄弟，他是宙斯的哥哥。亚特兰蒂斯

冥王 Hades // Pluto

火与锻造之神 赫菲斯托斯 Hephaestus // Vulkan

智慧女神 雅典娜 Athena // Minerva 雅典的得名，雅典娜给了雅典市民橄榄和波塞冬给了泉水，但是是咸的海水。

战争 阿瑞斯 Ares // Mars 和火神的妻子美神阿佛洛狄忒偷情被火神抓住；许多出丑

狩猎女神 阿尔特弥斯 Artemis 阿波罗的姐姐，射箭杀死了挚爱Orion(猎户座)

海妖塞壬 Siren，大英雄奥德修斯 Odysseus，特洛伊战争。 起因是"金苹果"神话，阿弗洛狄特帮特洛伊王子拐走了斯巴达王后美女海伦，导致斯巴达打特洛伊(在土耳其)。希腊围城特洛伊十年，最后奥德修斯献出木马计，佯退，特洛伊人把木马当战利品拉进城中，藏在里面的希腊人杀出，最后屠城特洛伊。奥德赛就是奥德修斯的故事的意思。回去路上，经过墨西拿海湾，他让海员用蜜蜡封住耳朵，他自己绑在船上，渡过了海妖塞壬歌声。

Medusa 美杜莎。本来是雅典娜神庙的美女祭司，在雅典娜神庙的祭坛被波塞冬夺贞，后被雅典娜惩罚把秀发变成了毒蛇，眼睛会石化。后来英雄珀尔修斯Perseus 借助雅典娜的青铜盾反射，没有直视，杀掉了美杜莎。后来美杜莎的头还被他用成工具石化了海怪刻托Cetus，救下了古埃塞俄比亚公主安德洛墨达（Andromeda），后来成为了英仙座和仙女座。

普罗米修斯 Prometheus 盗火 给人间带来火，被宙斯绑在山上，巨鹰撕裂，后来赫拉克勒斯射死了巨鹰。

奥菲斯 Orpheus 与 欧律狄克 Eurydice. 欧律狄克被毒蛇咬伤坠入冥界，奥菲斯美妙的音乐让地狱三头犬安静，受刑的人停止呻吟，哈迪斯流泪。哈迪斯破例让奥菲斯能带妻子回人间，两人一前一后，但路上不能回头看。在看到阳光的时候，奥菲斯回头，但欧律狄克的脚还在阴影里，欧律狄克的身体化成了一缕轻烟。

赫拉克勒斯 Heracles 希腊力量半神，以十二大功绩闻名。第二项功绩是消灭九头蛇。在勒纳沼泽，九头蛇的头被砍掉就能长出两个新头，赫拉克勒斯叫来侄子，他砍一个，侄子用火把那个蛇头的伤口烧掉。\
他是宙斯与凡人的儿子，被赫拉施咒，神志不清杀死了自己的妻子。后来人生清洗罪孽，肉身死亡后被牵引至奥林匹斯成神，与青春女神Hebe结婚。杀巨狮、砍九头蛇、捉牝鹿，擒野猪，洗牛圈，驱逐怪鸟，制服公牛，捉牝马，夺腰带，牵牛，摘金苹果，活捉地狱三头犬刻耳柏洛斯 (Cerberus)。

潘多拉 Pandora 宙斯报复普罗米修斯，捏了一个完美女性，潘多拉意为一切天赋的赠予者，被神祝福，嫁给普罗米修斯的弟弟，并赠送一个结婚礼物潘多拉魔盒。由于潘多拉也被赋予了好奇，它打开魔盒，释放出了疾病、贪婪、战争、痛苦等等，她关上，但却把希望关在了最底下。

伊卡洛斯的羽翼 Icarus 飞得太高被太阳融化，飞得太低被海水沾湿。得意忘形的故事。

阿喀琉斯 Achilles，特洛伊战争中的希腊战神，半神。作为半神，要么平庸长寿，要么名垂青史但早死。早年母亲把它放到冥河洗礼，刀枪不入，但由于母亲是抓着他右脚踝泡的，那里是弱点。特洛伊毒箭射中他，成了名垂青史但早逝的路。

西西弗斯 Sisyphus 精明的凡人，告发宙斯拐走河神女儿，把来索命的死神关进自家地牢。最后被惩罚在冥界推大石头上山。

俄狄浦斯 Oedipus 弑父娶母的神谕，从小被遗弃，给养父养大，解开狮身人面的斯芬克斯Sphinx谜题，得到底比斯王位。

德尔斐Delphi神谕 就是阿波罗神殿 阿波罗射杀远古巨蟒python，在德尔斐这里建立了自己的神殿。有一个女祭司，职位名Pythia，从岩石裂缝的轻烟入幻，通灵状态。

Nymph 宁芙仙女，精灵。 主神以后次要的女仙。\
有树木宁芙 Dyrads, 树木和森林\
泉水宁芙 Naiads, 溪流和清泉、湖泊\
海洋宁芙 Nereids, 海洋\
山脉宁芙 Oreads, 荒山、深谷和岩石.
